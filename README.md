# Hochzeitswebsite

Statische Informationsseite für die kirchliche Hochzeit am 02.10.2027 in Erlangen.

## Lokale Vorschau

`index.html` direkt im Browser öffnen. Es gibt keinen Build-Schritt.

## RSVP

Das Formular ist bewusst deaktiviert. Rückmeldungen sollen später über einen gesicherten Server-Endpunkt in die private Notion-Datenbank `📥 RSVP-Eingang` geschrieben werden. Keine Notion-Token oder personenbezogenen Daten in dieses Repository committen.

## Veröffentlichung

Vor der Veröffentlichung: Datenschutzhinweise vervollständigen, den Server-Endpunkt implementieren und testen, dann GitHub Pages konfigurieren.
